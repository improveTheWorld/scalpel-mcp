## 1. Principe Directeur : Loi d'Exécution Déterministe Zéro-Tour

1. **Auto-Exécution / Auto-Healing** : Chaque fois qu'un garde dans le code calcule avec certitude la correction exacte pour l'écrire dans `actionable_hint` (*"Use insert_after: 1"*, *"Use insert_after: N-1"*, *"Shrink the replace range to [a, b-1]"*, *"Call insert_block(parent=holder, anchor=where)"*, *"Retry without file_pattern"*), **refuser est une erreur de conception**. L'outil doit appliquer la transformation déterministe sur place et signaler l'ajustement dans `warnings`.
2. **Zéro `read_block` de récupération** : Lorsqu'une opération réussit (création, suppression) ou lorsqu'un refus est inévitable (conflit réel ou erreur de syntaxe), la réponse doit **toujours** livrer les identifiants canoniques `::`, le `numbered_text` frais et le `content_hash` prêts pour l'appel suivant dans le même tour.
